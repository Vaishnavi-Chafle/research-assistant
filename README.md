# Research Assistant

An AI-powered research assistant built using FastAPI, Python, and Google Gemini to help users explore technical topics and research questions.

**🚀 Live Demo:** [Try Research Assistant](https://research-assistant-t7ru.onrender.com)

**🛠️ Tech Stack:** Python · FastAPI · LangChain · Google Gemini · HTML · CSS · JavaScript

## Features

- AI-powered responses to user queries
- Interactive web-based interface
- FastAPI backend
- Google Gemini integration
- Deployed on Render

## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Vaishnavi-Chafle/research-assistant.git
   cd research-assistant
   ```

2. Install the dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Create a `.env` file and add your Gemini API key:

   ```env
   GEMINI_API_KEY=your_api_key_here
   ```

4. Start the application:

   ```bash
   uvicorn main:app --reload
   ```

5. Open `http://127.0.0.1:8000` in your browser.

## Deployment

The application is deployed on Render. Use the live demo link above to access it.
